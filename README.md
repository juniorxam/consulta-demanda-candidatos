# Consulta da demanda de candidatos por vaga

Página estática para consultar os dados do documento da demanda de candidatos por vaga do concurso da Saúde do Tocantins.

## Como usar

Abra [index.html](./index.html) no navegador. Filtre por cargo e município, use a busca rápida e baixe os resultados exibidos em CSV.

## Dados

A tabela tem 386 registros, em 15 municípios, com vagas, inscritos e candidatos por vaga. Os totais do documento são 5.124 vagas e 69.748 inscritos.

## Publicar com GitHub Pages

No repositório, acesse **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch **main** e a pasta **/(root)**, então salve. O GitHub publicará o `index.html` como site estático.
